# PEERS.md - Peer Agent Protocol

Use this file to define how the agent should interact with peer bots, copilots,
and other autonomous systems.

Things you can keep here:

- Collaboration norms with other agents
- Delegation and handoff rules
- When to trust, challenge, or ignore peer outputs
- Boundaries that prevent agent loops or noisy bot-to-bot chatter
- Shared etiquette for multi-agent workflows
